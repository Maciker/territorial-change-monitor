# Synthetic Navarre demo scene

Six 20×20 GeoTIFFs (red, NIR and SCL, before and after) and a recorded STAC catalog (`items.json`) used by `pnpm change-run` and the local viewer. They are **synthetic** arrays written by `tools/generate-raster-fixtures.mjs` (`pnpm fixtures:rasters`), not Sentinel-2 products, and contain no Earth observation pixels. The grid is placed on the example Navarre AOI in EPSG:4326 only so the pipeline can validate CRS and bounds; the item IDs mimic Copernicus naming for readability.

Raw values use Sentinel-2-like digital numbers with scale 0.0001, offset 0 and NoData 0 (recorded in each file's `GDAL_NODATA` tag and declared in `items.json`).

| Feature | Rows × columns (0-based) | Expected result at threshold 0.20 |
|---|---|---|
| Background vegetation, slight seasonal decline | everywhere else | NDVI change ≈ −0.03, not a candidate |
| Loss patch: vegetation to bare soil | rows 4–8, columns 3–8 (30 px) | 30 loss candidates |
| Gain patch: bare soil to vegetation | rows 13–16, columns 12–16 (20 px) | 20 gain candidates |
| Isolated stressed pixel | row 18, column 2 | 1 loss candidate (kept with `minimum_region_pixels: 1`) |
| Cloud in the after scene (SCL 9) over bare soil | rows 2–6, columns 13–18 (30 px) | masked, never a candidate |
| NoData column in the before scene | column 19 (20 px) | masked, never a candidate |

Valid-pixel coverage is 350 / 400 = 0.875. `test/demo-fixture.test.ts` checks these numbers. Regenerating the files must keep them byte-identical; commit any intended change together with its test update.
