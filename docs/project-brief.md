# Project brief

## Question

Can a reproducible workflow identify where a defined land-surface signal changed between two documented observation periods in a small Spanish area of interest?

## Deliverable

A map and report that identify candidate change, disclose image-selection criteria and limitations, and make the run repeatable.

## Success criteria

- Inputs, dates, cloud filtering, CRS, index formula, threshold, and outputs are documented.
- The process can be rerun from configuration.
- Results distinguish observed spectral change from claims about its real-world cause.
